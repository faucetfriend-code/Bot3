### HIGH Severity Finding (FIXED)

**File:** `trading_bot_v2/market_regime.py`  
**Line:** 309  
**Issue:** Use of weak MD5 hash for security  
**Fix:** Added `usedforsecurity=False` parameter

```python
# Before
return hashlib.md5(data_str.encode()).hexdigest()

# After
return hashlib.md5(data_str.encode(), usedforsecurity=False).hexdigest()
```

**Rationale:** MD5 is used here for change detection (hashing market data), not for cryptographic security purposes. The `usedforsecurity=False` flag explicitly indicates this is not a security use case.
