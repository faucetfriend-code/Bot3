# Campaign 2026-07-30: first PASS verdicts, and the directional gate A/B

**Setup.** 3 symbols (BTC-USDC, ETH-USDC, SUI-USDC), 12x2mo spread windows
per symbol anchored 2026-07-01 (BTC/ETH reach back to 2020-07; SUI clamps to
its 2023-05 listing), `BACKTEST_FUNDING_MODEL=historical` (ETH/SUI funding
ingested this day: 2019-11-27 / 2023-05-03, zero gaps),
`BACKTEST_HISTORY_LOOKBACK=100`, `VWAP_STOP_SOURCE=atr_structure`,
corrected equity accounting (post-6d9a42d), seeded engine. Two arms differ
in exactly one variable: `DIRECTIONAL_GATE=off` vs `enforce`.

This supersedes the 2026-07-28 8-year campaign as the reference result set:
that campaign ran flat funding, the broken VWAP stop, and BTC+SUI only.
Its verdicts (all six incumbents FAIL) are consistent with what follows.

**These are the first PASS verdicts this gate has ever issued.** Notes:

- `vwap_pullback` was designed and frozen the same morning - no parameter
  was tuned on any data, so multiplicity is ~1 and ETH/SUI are genuinely
  out-of-design. Still: the sample is 63% trending_strong bars and the
  strategy is trend-following; a trend-light epoch is its untested regime.
- `funding_arb`'s first real measurement (historical funding) is PF 0.73:
  funding-as-carry loses. Funding's value here is directional (the gate's
  contrarian leg), not carry.
- `vwap_scalping` at its best-ever configuration (structure stop) is still
  PF 0.89. The fade is closed; see docs/VWAP-SIGNAL-STUDY.md.

## Arm 2: DIRECTIONAL_GATE=enforce (identical otherwise)

| strategy | trades off -> enf | PF off -> enf | PSR off -> enf |
|---|---|---|---|
| mean_reversion | 1,279 -> 985 (-23%) | 0.87 -> **1.02** | 0.03 -> 0.58 |
| vwap_scalping | 1,661 -> 903 (-46%) | 0.89 -> **0.97** | 0.04 -> 0.37 |
| ma_crossover | 44 -> 28 | 1.04 -> **1.18** | 0.55 -> 0.65 |
| momentum_scalping | 254 -> 247 | 1.85 -> **1.86** | 1.00 -> 1.00 |
| vwap_pullback | 4,551 -> 4,551 | 1.61 (unchanged) | unchanged |
| grid / liq_capture / funding_arb | exempt - identical | identical | identical |

**The gate did exactly what it was built to do and nothing else:**

- Every gated mean-reversion-style strategy improved: the trades it vetoed
  were net losers (mean_reversion +0.15 PF on 23% fewer trades,
  vwap_scalping +0.08 on 46% fewer).
- It cost the winners nothing: momentum -7 trades for +0.01 PF;
  vwap_pullback untouched (its own 4h-stack gate already implies
  alignment).
- The exempt set (GridTrading, FundingArb, LiquidationCapture) is
  bit-identical across arms, confirming the plumbing.
- No FAIL was converted to PASS. The gate improves losers; it does not
  manufacture winners.

## Standing recommendation

`DIRECTIONAL_GATE=enforce` for future campaigns and any live deployment:
measured strictly-better-or-equal for every non-exempt strategy. The two
PASS strategies (momentum_scalping, vwap_pullback) are the only candidates
for live testnet deployment; everything else remains disabled.

Reproduce: `trading_bot_v2.validation.runner --symbols
BTC-USDC,ETH-USDC,SUI-USDC --windows 12 --window-months 2 --window-mode
spread --span-years 6 --anchor-end 2026-07-01 --once` with the env above.
