<objective>
Migrate the Bot 3 trading system from SQLite to TimescaleDB for time-series optimized storage.

Purpose: SQLite lacks hypertable partitioning, continuous aggregation, and compression needed for high-volume
time-series trading data (market candles, funding payments, signals). TimescaleDB on PostgreSQL provides
automatic partitioning by time, native compression, and significantly faster time-range queries.

Output: Working TimescaleDB instance with migrated data, updated database.py with PostgreSQL support,
backward-compatible SQLite fallback, and comprehensive migration scripts.
</objective>

```python
"""
SQLite to PostgreSQL/TimescaleDB migration script.

Reads all data from the existing SQLite database and inserts into PostgreSQL.
Handles type conversions: SQLite strings -> PostgreSQL TIMESTAMPTZ/DOUBLE PRECISION/JSONB.
"""

import sqlite3
import psycopg2
import psycopg2.extras
import os
import sys
import json
import logging
from datetime import datetime
from typing import List, Dict, Any, Optional, Tuple
from contextlib import contextmanager

logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")
logger = logging.getLogger(__name__)

# Configuration from environment
SQLITE_PATH = os.getenv("DATABASE_PATH", "trading_bot.db")
PG_HOST = os.getenv("DATABASE_HOST", "localhost")
PG_PORT = int(os.getenv("DATABASE_PORT", "5432"))
PG_DB = os.getenv("DATABASE_NAME", "trading_bot")
PG_USER = os.getenv("DATABASE_USER", "trading_bot_user")
PG_PASSWORD = os.getenv("DATABASE_PASSWORD", "trading_bot_secure_password")

# Tables to migrate in order (respecting foreign keys)
TABLES_TO_MIGRATE = [
    "account_profiles",
    "subaccount_configs",
    "trades",
    "positions",
    "market_data",
    "signals",
    "performance_metrics",
    "funding_payments",
    "funding_rate_history",
    "pacifica_positions",
    "grid_state",
    "grid_levels",
    "regime_history",
    "capital_approvals",
    "balance_history",
    "market_info_history",
    "market_parameter_changes",
    "market_availability_history",
]
```

Implement these key functions:
- `get_sqlite_connection() -> sqlite3.Connection`: Open SQLite with Row factory
- `get_pg_connection() -> psycopg2.extensions.connection`: Open PostgreSQL with dict-like cursor
- `convert_timestamp(value: Any) -> Optional[datetime]`: Convert SQLite string timestamps to Python datetime for TIMESTAMPTZ
- `convert_json(value: Any) -> Any`: Parse JSON strings to Python objects for JSONB columns
- `convert_real_to_double(value: Any) -> Optional[float]`: Cast to float, handle None/empty
- `migrate_table(sqlite_conn, pg_conn, table_name: str, batch_size: int = 1000) -> int`: Read all rows from SQLite, transform types, batch insert into PostgreSQL using `executemany` with `ON CONFLICT DO NOTHING`
- `main()`: Run migration table by table, print row counts for each, handle errors gracefully

The script must:
- Use batch inserts (1000 rows at a time) for performance
- Handle NULL values correctly in type conversions
- Use `ON CONFLICT DO NOTHING` to be idempotent
- Print progress with row counts per table
- Create a backup of the SQLite database before migration (`trading_bot_backup_{timestamp}.db`)
- Log total migration time
- Exit with code 0 on success, 1 on failure
